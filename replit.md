# SolarFast on Replit

This is a React/Vite application. Node.js 22 or newer is required.

Use the **Start application** workflow to run the Vite development server on port 5000 and open the web preview. From the shell, the equivalent command is `npm run dev`.

Dependencies are listed in `package.json` and `package-lock.json`. The app does not need a backend or API keys; project data is stored in the browser.

For checks, run `npm test`, `npm run lint`, and `npm run build`.
