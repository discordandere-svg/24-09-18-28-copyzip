# SolarFast Energy Advisor

The SolarFast web app builds one connected home-energy plan for solar panels,
home batteries, heat pumps and EV charging. Recommendations use the complete
system and balance return, sustainability, sizing and comfort.

## Local development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

No API key or server is required. Project data is stored in the browser.

## Verification

```bash
npm test
npm run lint
npm run build
```
